### 🎬 AI Video Assistant — Multimodal Video Intelligence & RAG

> Drop in a YouTube URL or a local recording → get transcripts, summaries, action items, key decisions, and a chat interface over the whole thing.

[![AI Video Assistant](https://github-readme-stats.vercel.app/api/pin/?username=mohddawoodkh&repo=AI-Video-Assistant&theme=nord&border_color=7dd3fc&title_color=7dd3fc&icon_color=7dd3fc&text_color=c9d1d9)](https://github.com/mohddawoodkh/AI-Video-Assistant)

| Layer | Technology |
|---|---|
| Media Pipeline | yt-dlp, pydub, FFmpeg (extraction, conversion, chunking) |
| Speech-to-Text | OpenAI Whisper (English), Sarvam AI (Hindi / Hinglish) |
| Summarization | LangChain + Mistral AI map-reduce |
| RAG Q&A | ChromaDB + HuggingFace all-MiniLM-L6-v2 embeddings + Mistral AI |
| Interface | Streamlit dashboard + CLI |

**✨ Highlights:** multilingual transcription (English + Hindi/Hinglish) • extracts action items with owner & deadline • ask questions over any video's transcript
